# ParkD
Features

Register and manage vehicles.

View, update, and delete records.

Track parking fees and vehicle status.

Dashboard with parking statistics.

Technologies

Node.js, Express.js, MongoDB Atlas, Mongoose, HTML, CSS, JavaScript, Postman.

API Endpoints

POST /api/vehicles – Create

GET /api/vehicles – Read all

GET /api/vehicles/:id – Read one

PUT /api/vehicles/:id – Update

DELETE /api/vehicles/:id – Delete

API Testing: Postman Desktop.

Database: MongoDB Atlas.
